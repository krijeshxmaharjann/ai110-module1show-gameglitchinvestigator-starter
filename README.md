## 📝 Document Your Experience

🎮 Game Glitch Investigator: The Impossible Guesser
🚨 The Situation

The project is a Streamlit number-guessing game that was generated by AI. The goal of the game is to guess a randomly generated secret number within a limited number of attempts.

The original game contained several bugs that made the game confusing and difficult to play correctly.

🕵️‍♂️ Bugs Found
Bug 1: Secret/State Handling

Streamlit reruns the Python script when the user interacts with buttons and widgets. Game state therefore needs to be stored in st.session_state so that important values persist between reruns.

The secret number was stored in st.session_state, but the original code also changed the secret's type between an integer and a string during different attempts. This caused the guessing comparison to behave incorrectly.

Bug 2: Higher/Lower Hints

The original Higher/Lower messages were reversed.

For example, when the guess was greater than the secret, the game incorrectly told the player to go HIGHER.

I fixed the comparison so that:

Guess greater than secret → Too High → Go LOWER
Guess less than secret → Too Low → Go HIGHER
Guess equal to secret → Win
Bug 3: Game Reset

The New Game functionality needed to reset the complete game state. I updated it so that a new game resets:

Secret number
Attempts
Score
Game status
Guess history
Bug 4: Score Updating

The scoring function existed in logic_utils.py, but the application was not calling it after a valid guess. I added the update_score() call so the score changes after each guess.

🛠️ Fixes Applied

I made the following changes:

Used st.session_state.secret as the persistent source for the secret number.
Removed the incorrect conversion of the secret number between int and str.
Corrected the Higher/Lower comparison logic.
Changed the initial attempt count from 1 to 0.
Updated New Game to reset the game state.
Added the missing score update.
Moved the game logic into logic_utils.py.
Updated app.py to import the logic functions from logic_utils.py.
Tested the refactored functions using pytest.

## 📸 Demo Walkthrough

Open the Streamlit game and select a difficulty level from the sidebar.
Open Developer Debug Info to view the current secret number, attempts, score, difficulty, and guess history.
Enter a number and click Submit Guess 🚀. The game correctly tells the player whether the guess is too high or too low.
Continue guessing until the secret number is found. A correct guess displays a winning message and the final score.
Click New Game 🔁 to reset the game. The attempts, score, history, and game status reset and a new secret number is generated.
The Show hint option can be enabled or disabled to control whether the Higher/Lower hint is displayed.
